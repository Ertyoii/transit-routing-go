# Walking contract v1

A snapshot descriptor binds provider, graph, revision, cost model and source evidence. Local graph snapshots are SHA-256 hashes of canonical node/edge/descriptor contents, independent of input order. Change topology, costs, permissions, coordinates, accessibility or provenance and the snapshot changes. Cache keys include snapshot, ordered endpoints, role, bound, accessibility and absorbing destination. Errors are not cached as unreachable; caller mutations cannot alter stored witnesses.

Directed edges are explicit. Node IDs are strings in a snapshot namespace (raw OSM uses decimal IDs; normalized transit uses dataset IDs). Optional coordinates are decimal WGS84 latitude/longitude and must match the node exactly in the local provider. A future adapter must explicitly document coordinate resolution and retain connector witnesses. There is no nearest-node fallback.

Each path contains positive-second physical segments and source/revision/edge-ID witnesses. A zero-duration path is allowed only as a zero-edge self path. The local graph conservatively requires yes at nodes and edges for accessible-only traversal. The identity self path does not certify physical accessibility or entry; transit queries separately validate endpoint accessibility. Unknown stays unknown. No live closure, signal, lift or kerb guarantee is implied.

Roles are access, egress, transfer and direct; internal closure builds candidates for the caller's eventual role check. `StopAt` is absorbing. `Reach.Targets` optionally restricts reconstructed terminal paths while still permitting intermediate traversal; empty means all reachable nodes. The transit adapter passes useful terminals using an immutable prepared `graph.TargetSet`, preserving the old walker's behavior and avoiding reconstruction of every street prefix. `ReachWithTargets` adds explicit per-query endpoints to that snapshot-bound set; no implicit target is invented. Search and witness output have separate finite budgets. Batch processing shares one origin/policy search, retains only one such search at a time and reconstructs results into the original request order.

Local defaults: at most 2,000,000 settled nodes and 10,000,000 edge visits per origin search, 1,000,000 matrix cells, and 2,000,000 returned segments per entire operation. Context is checked during search and reconstruction. A budget/cancellation error returns no partial matrix/closure. HTTP defaults are stricter: 1 MiB request body, 10,000 cells and a five-second provider deadline, with duplicate/unknown/trailing JSON rejected. Both matrix axes must be nonempty; empty axes return ErrInvalid and no rows. The client must still interpret the returned descriptor and capability errors.

`CheckResult` checks structural continuity, total cost, witness presence and request binding. `graph.ValidatePath` additionally compares every segment to the immutable source graph, independently of search. Neither proves physical truth of external data or absence of a path. Unreachable correctness is checked by independent bounded references. Duration-only external responses cannot be materialized as guessed path witnesses.

External adapters implement `Provider`, optionally adding duration/batch/matrix capabilities. `transit.Acquire` is an explicit bounded preparation operation. It uses one batch if offered, otherwise documented sequential route calls, checks every result and verifies the snapshot did not change. It rejects role-dependent, accessible-only or absorbing-node acquisitions because the current timeless footpath schema cannot encode those restricted subgraphs. A provider lacking route witnesses cannot satisfy this acquisition contract. External service endpoints and authentication belong to the implementing application.

`Catalog.Bind(dataset, explicitNodes)` declares provider-node → transit-stop anchors. Every request endpoint must be explicitly bound, even when its spelling equals a transit ID. Additional observed interior nodes may be bound intentionally, preserving boarding and absorbing destinations. Unknown nodes/stops, duplicate source bindings and multiple provider nodes aliasing one transit stop fail. Separate station entrances need positive witnessed connectors to a single explicitly bound boarding anchor. The declaration binds the full catalog (provider identity/version/snapshot and witnesses) and the base dataset fingerprint; stale or modified declarations fail. Anchor-map input order does not change identity. This is an explicit modeling assertion, not independent physical proof.

`Catalog.Materialize(dataset, bindings)` returns the dataset plus node/segment mappings back to the unchanged source catalog. `Catalog.Apply(dataset, bindings)` is its dataset-only wrapper. Unbound interior vertices are deterministically namespaced by the complete binding declaration, including provider/catalog and base dataset, and have unknown accessibility. They never reuse an existing transit stop merely by string equality; a generated-ID collision is an error. Different acquisitions, provider versions, binding maps and base datasets cannot silently connect private interiors. Persist the returned mapping, bindings and source catalog for reconstruction. Footpath IDs and provenance include binding identity.

Segments remain separate so explicitly bound interior destinations stay absorbing. The selected union is a finite new graph and can omit provider-wide alternatives; recombination within it is possible. It does not preserve provider-global identity top-k. `Catalog.MaterializeLayer(dataset, bindings, explicitRemovalIDs)` and its dataset-only `ApplyLayer` wrapper replace only named walking edges and preserve all other edges and transfer rules. Unknown/duplicate removals fail. Existing stops, including now-unused prior interior nodes, are preserved; no implicit node cleanup or cross-provider aliasing occurs. Changed data requires rebuilding timetable indexes. This explicit API replaces the unsafe pre.1 signatures that inferred endpoint/node joins.

```go
bindings, err := catalog.Bind(dataset, []transit.NodeBinding{
    {ProviderNodeID: "street-origin", TransitStopID: "stop-origin"},
    {ProviderNodeID: "street-destination", TransitStopID: "stop-destination"},
})
if err != nil { return err }
materialized, err := catalog.Materialize(dataset, bindings)
if err != nil { return err }
// Persist materialized.Mapping, bindings and catalog with materialized.Dataset.
```

OSM extraction/permission audits remain preprocessing. `osm.Load` verifies exact graph/PBF hashes, permission profile and nominal `max(1,ceil(metres/1.4))` consistency; it preserves directed edges and declares access unknown. It does not independently recalculate PBF permission truth. A separate pinned geometry/permission audit is required for any real graph input. Different speed/crossing models need a new explicitly versioned adapter; they must not silently reuse the nominal cost identity.

Timing boundaries: provider acquisition/loading/materialization are preprocessing. Query walking in prepared local graphs is core work. Validation/selection is response work. If an external service is later measured, record acquisition/network/cache costs separately; never hide remote latency inside a kernel's core estimate or divide batch makespan into per-query latency.
