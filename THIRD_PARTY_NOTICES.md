# Licensing and data boundaries

Original Go implementation, tests and project documentation are MIT licensed in
LICENSE. This does not relicense third-party reference material or transit data.
The synthetic fixture data has its own CC0 notice where included.

The Go implementations were authored from algorithm descriptions and inspected
reference implementations; reference C++ source, papers and figures are not
included. Retained MIT notices attribute the KIT ITI Algorithmics Group and
Patrick Steil reference projects. They remain applicable to their original
material; do not remove them from a redistribution of substantial adaptations.
The provenance records inspected for this release did not identify incompatible
copied code. This is a source inventory, not a claim that algorithm ideas or
every possible external data source share the project code license.

No operator timetable, OSM extract, derived walking graph, real-data query set,
benchmark output, screenshot, private system information or production-system
report is bundled. The local CSA controls are independently authored research
implementations; no equivalence to any external production system is claimed.

OSM/Geofabrik data is attributed to OpenStreetMap contributors under ODbL 1.0:
https://www.openstreetmap.org/copyright
OSM is a street source, not a timetable. Importing a graph does not establish
its physical correctness, accessibility or redistribution rights. Database and
derived-database obligations require a source-specific distribution assessment.

The Vorld Singapore GTFS project's software MIT notice is retained separately.
Its NOTICE distinguishes LTA, SimplyGo, SBS Transit and community inputs; it is
not a blanket permission to redistribute schedules or modeled data. No such
source or derived data is included here. Frequency models are not exact/live
departure schedules. Any future dataset release needs its own rights review,
attribution, provenance and immutable hashes.
